## 两种扩展方式

**原生组件**是经过审阅、随应用打包的可信 ES Module。它直接参与桌面渲染，使用注册表、配置表单和生命周期接口；不能把任意远程脚本作为原生组件安装。

**社区组件**是作者托管的独立网页，通过公开 JSON 清单被发现。桌面显示静态入口，用户在详情窗口点击“运行”后才加载隔离 iframe；SDK 只交换本实例数据和显示环境。

两套版本号和接口独立。原生 `apiVersion: 3` 不等于社区清单的 `version: 1`，两者也不等于桌面存储的 `schemaVersion: 5`。
