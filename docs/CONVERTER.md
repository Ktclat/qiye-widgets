# 换算器

换算器整合计算器与进制转换，统一提供 20 个分类、117 个度量单位和 40 种常见货币。旧计算器与进制卡片在加载本机数据或导入备份时自动升级，保留卡片 ID、分组、尺寸和自定义名称。旧进制卡片打开后仍直接进入进制转换，保留全部输入和格式偏好；组件目录只保留换算器入口。

## 功能与交互

| 分类 | 支持范围 |
| --- | --- |
| 计算器 | 加减乘除、括号、百分比、正负号、平方、平方根、倒数、科学计数法和本次计算记录；Enter 计算，Esc 清空 |
| 进制转换 | 2–36 进制同时输出；精确大整数、小数与循环节；8–128 位有符号 / 无符号整数、补码、位视图和范围校验 |
| 货币汇率 | 人民币、美元、欧元、港币、新台币、澳门元、日元等 40 种货币；按需联网、双向换算、来源日期和缓存状态 |
| BMI | 公制 cm/kg、英制 in/lb，切换单位保留实际身高体重；CDC 20 岁及以上成人分级 |
| 日期 | 日期间隔、包含开始当天、周数与平日数；年月日加减，支持负数、闰年和月底收敛 |
| 长度 / 面积 / 质量 / 体积 | 公制、英制、美制和常见市制；美制/英制液量、金衡/常衡盎司分别标注 |
| 温度 / 时间 / 速度 / 角度 | °C、°F、K、°R；纳秒至周；km/h、m/s、mph、节；度、弧度、百分度、周、角分、角秒 |
| 力 / 压力 / 能量 / 功率 | N、kN、kgf、lbf、dyn；Pa、bar、atm、psi、mmHg、Torr；J、cal、kWh、eV；W、hp、PS 等 |
| 数据存储 / 频率 | bit、B、kB–TB、KiB–TiB，明确 1000/1024 进位；Hz–GHz、rpm |
| 时间戳 | 秒、毫秒与带 Z / 时区偏移的 ISO 时间互转；8 个常用时区、夏令时、负时间戳和“现在” |

单位支持编辑任意一侧、交换方向、一键复制、同时查看其他常用单位。分类搜索同时匹配中文、英文、单位符号和 BIN / OCT / DEC / HEX 等进制别名。单位换算结果可选 0–12 位小数，极大或极小值用科学计数法；计算采用 JavaScript 浮点数，显示值会舍入。进制转换单独使用 BigInt 与精确分数运算，支持 1–128 位小数截断及循环节标记，不经过浮点转换。

细窄单行标题栏固定 46px，左侧为组件名称，右侧为分类搜索、设置、最大化和关闭。桌面卡片支持 1×1、1×2、2×1、2×2、4×2。常规窗口左侧是分类导航，主体按计算器、换算、BMI 和日期的各自任务组织；窄屏切换为下拉分类。进制页采用通栏输入和对齐的结果行，格式设置、目标进制和输入示例按需展开；设置按钮随分类切换用途，Esc 收起后返回按钮焦点。深浅主题使用栖页的字体、圆角、线条图标与低饱和绿色。打开窗口聚焦标题，控件只在键盘导航时出现焦点轮廓。

## 数据与计算约定

- 每张卡片单独保存最近分类、各类别单位对、小数位数和汇率联网偏好；沿用本机保存、JSON 备份和 WebDAV。保存失败保留独立草稿，可重试。
- 进制输入、输出进制、位宽和格式保存在该卡片的 `data.radix`，与其他分类共用一个保存队列。切换分类不会覆盖尚未完成的保存；失败草稿在本次会话关闭重开后仍可重试。旧版换算器缺少此字段时补默认值，旧进制卡片迁移后重复校验不再改变数据。
- 输入金额、身高体重、算式、计算记录和临时日期只在当前窗口内存中，关闭即清空。汇率请求只包含两个币种，不包含金额或其他计算内容。
- 汇率默认不联网。用户主动启用后，扩展按需申请 `https://api.frankfurter.dev/*`，使用 Frankfurter v2 的每日参考汇率；API 不需要密钥。缓存单独存于 `qiye.converter.rates.v1`，最多 64 个币种对，不进入备份或同步。24 小时后尝试更新，失败保留原日期和明确的缓存提示；未取得汇率时不伪造结果。切换类别或币种取消旧请求，晚到响应不覆盖当前结果。
- 参考汇率不含银行买卖价差或手续费。周末、节假日沿用数据源最近公布值；始终显示汇率日期和获取时间。
- 市斤 = 500 g，市两 = 50 g；市尺 = 1/3 m，市亩 = 2000/3 m²。海里 = 1852 m。烹饪容量为美制。卡和千卡使用热化学定义，英热单位使用 IT 定义。
- 温度为绝对温度，低于绝对零度时提示错误。时间单位中的一天固定为 24 小时、一周为 7 天；月份、年份交由日期计算处理。
- 日期按 UTC 公历日序号计算，避免夏令时造成少一天；默认不计开始当天。反向日期输出负天数。平日仅扣除周末，不推断各地法定假期或调休。加减年月先收敛到目标月最后一天，再加减天数，支持 0001–9999 年。
- 时间戳反向输入必须带 `Z` 或显式时区偏移，拒绝无时区时间和无效日期；显示时区由 `Intl.DateTimeFormat` 处理。
- BMI 按原始值分级，显示到一位小数；采用 CDC 成人 20+ 的 18.5、25、30 分界。它是筛查指标，不作为诊断，也不用于儿童或孕期评估。

## 公开参考与实现决定

调研日期：2026-10-15；进制整合补充调研：2026-10-18。所有界面与代码由栖页独立实现。

| 来源 | 采用的决定 |
| --- | --- |
| [iTab 公开界面](https://go.itab.link/) / [更新日志](https://itab.link/changelog) | 延续桌面小组件、紧凑工具窗口、细标题栏；不调用 iTab 私有接口 |
| [Microsoft Calculator](https://github.com/microsoft/calculator) | 计算器、单位、货币与日期按用途分类；保留计算记录与双输入数值模式，独立实现运算 |
| [MDN BigInt](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/BigInt) | 进制引擎保留整数及分数的精确表示，不把大整数转换为 Number；沿用独立的数值 / 位模式解释与范围校验 |
| [WAI-ARIA Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) | 格式和目标选择使用原生按钮及 `aria-expanded` / `aria-controls`，支持 Enter、Space；Esc 收起并回到触发按钮 |
| [NIST SI 转换因子](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors) / [SI 温度](https://www.nist.gov/pml/owm/si-units-temperature) | 使用规范转换因子；区分偏移温度、英美容量和不同马力、热量口径 |
| [NIST 二进制前缀](https://physics.nist.gov/cuu/Units/binary.html) | 明确区分 kB/MB 与 KiB/MiB |
| [Frankfurter 官方 API](https://frankfurter.dev/) | v2 每日参考汇率，币种对响应校验、来源日期、缓存与失败状态 |
| [CDC 成人 BMI 分级](https://www.cdc.gov/bmi/adult-calculator/bmi-categories.html) | BMI = kg/m²，成人 20+ 分界与适用范围 |
| [MDN Date.UTC](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/UTC) / [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat) | 使用公历日期算术，并把时间戳时区显示交给浏览器标准库 |
